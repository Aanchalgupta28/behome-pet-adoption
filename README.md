# BeHome | Pet Adoption Page 🐾

A responsive pet adoption landing page built with HTML and CSS only (no frameworks).
A practice project where I learned to build and fix layouts on my own.

## What I built
- Responsive layout for mobile, tablet and desktop
- Flexbox layouts, hover effects and transitions
- Fixed navbar, sidebar and sign-in section

## What I learned
- Flexible sizing with flex, max-width and units
- Why fixed widths break layouts, and how to fix them
- Writing media queries where my layout actually breaks
- Debugging with browser DevTools

## Challenges I faced
- My first version was not responsive, so I rewrote the layout using flex and max-width instead of fixed widths.
- Hover effects were shifting the layout, so I replaced font-size changes with transitions.
