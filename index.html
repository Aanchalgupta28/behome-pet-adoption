Give a Pet a Forever Home
by BeHome Team  • Web Design

A responsive pet adoption page built with HTML and CSS

Hello!
BeHome is a pet adoption page I built to practice HTML and CSS.
The idea is simple: help people find a pet and give it a home in a few easy steps.
I focused on a clean layout, readable text and a friendly look, using Flexbox, a fixed navbar.
It adapts to different screen sizes using Flexbox and media queries. A mobile menu with JavaScript is coming next.
This page is part of my web development journey....
